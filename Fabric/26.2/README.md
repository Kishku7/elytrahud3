# ElytraHud3 - Fabric (Minecraft 26.2)

Client-only elytra-flight HUD mod for the **Fabric** loader (Fabric/Quilt), Minecraft **26.2** (pre-release line).

This is a standalone Fabric build - no Architectury, no shared `common` module.

## Build

```
./gradlew build
```

(Windows: `.\gradlew.bat build`)

Requires JDK 25 (Minecraft 26.x toolchain).

## Output

`build/libs/elytrahud3-<version>.jar`

## Dependencies

- Fabric API (required)
- ModMenu, Do a Barrel Roll (optional)
